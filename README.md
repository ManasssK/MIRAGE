# Mirage

Mirage is a social media platform inspired by Instagram that introduces the concept of multiple profiles under a single account. Instead of creating separate accounts for different purposes, users can manage multiple independent profiles and switch between them seamlessly. Each profile maintains its own identity, posts, and social interactions, providing a more organized and flexible social networking experience.

## Main Features

* Multi-profile management under a single account
* Secure user authentication
* Create and share image posts
* Like and comment on posts
* Follow and unfollow users
* User profile customization
* Search for users
* Responsive and intuitive user interface
* Cloud-based image storage using Cloudinary
* MongoDB-powered data management
